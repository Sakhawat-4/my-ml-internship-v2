# ML Portfolio & Internship Tracker

**Author:** Sakhawat-4
**Purpose:** This repository serves as my public portfolio and work tracker for the Fly Rank ML Internship. It contains all my completed assignments, from exploratory data analysis to building a live portfolio feature.

## What This Project Does
- **Tracks my ML Internship progress:** Each week's assignment is documented and submitted here.
- **Showcases my portfolio:** The `index.html` file is my live, public portfolio website.
- **Demonstrates a working backend feature:** The portfolio includes a fully functional contact form that sends messages to my email.

## Who This Is For
- **FlyRank Internship Reviewers:** To verify my completed work and understand my process.
- **Potential Employers:** To see practical examples of my ML and web development skills.
- **Anyone Learning ML:** To see a project structure and workflow for a real-world ML internship.
